# 🗺️ US State Game

A fun Python Turtle game where you guess the names of U.S. states and watch them appear on the map.

## ✨ Features
- Interactive guessing game.
- Shows correct state names directly on the map.
- Saves missed states into a CSV file.
- Beginner-friendly project using Python, Turtle, and Pandas.

## 🚀 Getting Started

### Requirements
- Python 3.x
- Pandas installed
- Turtle graphics support

### Installation
```bash
pip install pandas
```

### Run the game
```bash
python main.py
```

## 🎮 How to Play
- A popup box will ask you to type a U.S. state name.
- If your answer is correct, the state will appear on the map.
- Type `Exit` anytime to stop the game.
- At the end, the missed states are saved in `states_learn.csv`.

## 📁 Project Files
- `main.py` - Main game logic.
- `50_states.csv` - State names with x/y coordinates.
- `blank_states_img.gif` - Blank map image.
- `states_learn.csv` - File created after the game with missing states.
